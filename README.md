# Sharif Hadidi Portfolio

Personal portfolio for Sharif Hadidi: product strategy, platform leadership, enterprise delivery, and research.

## Website

https://www.sharifhadidi.com/

Static HTML, CSS, and JavaScript. No dependency installation or build step is required. GitHub Pages publishes the root of the `master` branch. `CNAME` retains the custom domain.

## Content

- Home, Work, Experience, About, Approach, and Contact pages.
- Eight case studies, including KabuK, Caesars Entertainment, American Express, AR-t, Odyssey, SenseData, ZenCasa, and SnapSecure.
- Original research assets and downloadable resume.
- Social links and separate 15- and 30-minute Cal.com booking links.
- Responsive layouts and blue light/dark themes.

Edit the root HTML files, `style.css`, and `script.js`. Shared assets are in `assets/`. Historical source files and unrelated legacy assets remain available in the repository history and retained directories.
